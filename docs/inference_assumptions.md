# Statistical Inference Assumptions & Uncertainty Specification

This document formalizes the statistical conditions, theoretical properties, and limitations of the confidence interval and uncertainty estimation methods implemented in ReversalLab Milestone M3B-2.

## 1. Scope & Framework

We operate in a single-position contextual bandit setting with discrete action space $\mathcal{A} = \{1, \dots, K\}$.
The target estimand is the expected value of a fixed candidate evaluation policy $\pi_e$:
$$V(\pi_e) = \mathbb{E}_{x \sim P(x)}\left[\sum_{a=1}^K \pi_e(a \mid x) \, q^*(x, a)\right], \qquad q^*(x, a) = \mathbb{E}[r \mid x, a].$$

Observations in the logged dataset $\mathcal{D} = \{(x_i, a_i, r_i, p_i)\}_{i=1}^N$ are generated by a logging policy $\pi_0$ with observed propensities $p_i = \pi_0(a_i \mid x_i)$.

---

## 2. Taxonomy of Inference Assumptions

| Dimension | ReversalLab Synthetic Scope | Real-World / Non-Standard Setting (Not Assumed) |
|---|---|---|
| **Candidate Policy** | **Fixed:** $\pi_e$ is fixed a priori, completely independent of the logged data $\mathcal{D}$. | **Learned/Optimized:** $\pi_e$ selected via policy optimization on $\mathcal{D}$ (introduces adaptive bias, requiring uniform concentration / empirical process control). |
| **Logging Propensities** | **Known & Exact:** $p_i = \pi_0(a_i \mid x_i)$ recorded at decision time. Strictly positive ($p_i > 0$). | **Estimated:** Propensities estimated post-hoc via logistic regression or classification (introduces propensity-model error and nuisance covariance). |
| **Sampling Process** | **i.i.d.:** Rows are independent and identically distributed draws from stationary distribution $P(x, a, r)$. | **Clustered / Sequential:** Repeated interactions per user (`group_id`), session-level feedback, or non-stationary drift. |
| **Reward Nuisance Estimation** | **Cross-Fitted ($K$-fold):** $\hat{q}^{(-k(i))}$ trained on disjoint folds $\mathcal{D} \setminus F_{k(i)}$. | **In-Sample / Plug-in:** $\hat{q}$ fit on the entire sample (causes overfitting bias and optimistic uncertainty). |
| **Uncertainty Condition** | **Unconditional:** Standard errors reflect sampling variation over both contexts $x \sim P(x)$ and rewards $r \sim P(r \mid x, a)$. | **Conditional on Contexts:** Treats contexts $\{x_i\}_{i=1}^N$ as fixed design points. |
| **Guarantee Horizon** | **Asymptotic:** Justified as $N \to \infty$ via the Central Limit Theorem and Double/Debiased Machine Learning (DML). | **Finite-Sample:** Exact non-asymptotic coverage (requires strong concentration bounds or conformal prediction). |

## 3. Estimator-Specific Influence Scores & Variance Decompositions

### 3.1 Inverse Probability Scoring (IPS)
- **Estimator:** $\hat V_{\mathrm{IPS}} = \frac{1}{N} \sum_{i=1}^N w_i r_i$, where $w_i = \frac{\pi_e(a_i \mid x_i)}{p_i}$.
- **Uncentered Influence Score:** $\psi_i^{\mathrm{IPS}} = w_i r_i$.
- **Asymptotic Variance:** $\sigma^2_{\mathrm{IPS}} = \mathrm{Var}(w_i r_i)$.
- **Empirical Variance:** $\widehat{\mathrm{Var}}(\psi^{\mathrm{IPS}}) = \frac{1}{N-1} \sum_{i=1}^N (w_i r_i - \hat V_{\mathrm{IPS}})^2$.
- **Standard Error:** $\widehat{\mathrm{se}}_{\mathrm{IPS}} = \frac{\widehat{\mathrm{sd}}(\psi^{\mathrm{IPS}})}{\sqrt{N}}$.
- **Inference Requirement:** Finite variance $\mathbb{E}[(w_i r_i)^2] < \infty$. When overlap is weak, $w_i$ is heavy-tailed, causing the Berry-Esseen bound to deteriorate. In finite samples, Wald intervals undercover significantly.

### 3.2 Self-Normalized IPS (SNIPS)
- **Estimator:** $\hat V_{\mathrm{SN}} = \frac{\sum_i w_i r_i}{\sum_i w_i}$.
- **Delta-Method Influence Score:**
  $$\psi_i^{\mathrm{SNIPS}} = \frac{w_i}{\bar{w}} \big(r_i - \hat V_{\mathrm{SN}}\big), \qquad \bar{w} = \frac{1}{N} \sum_{j=1}^N w_j.$$
- **Standard Error:**
  $$\widehat{\mathrm{se}}_{\mathrm{SNIPS}} = \frac{\sqrt{\sum_{i=1}^N w_i^2 (r_i - \hat V_{\mathrm{SN}})^2}}{\sum_{i=1}^N w_i} = \frac{\sqrt{\frac{1}{N}\sum_{i=1}^N (\psi_i^{\mathrm{SNIPS}})^2}}{\sqrt{N}}.$$
- **Inference Requirement:** SNIPS is a ratio estimator with $O(1/N)$ finite-sample bias. Its delta-method standard error is asymptotically valid if $\mathbb{E}[w_i^2] < \infty$, but under heavy tails its sampling distribution remains skewed.

### 3.3 Direct Method (DM)
- **Estimator:** $\hat V_{\mathrm{DM}} = \frac{1}{N} \sum_{i=1}^N \sum_{a=1}^K \pi_e(a \mid x_i) \, \hat{q}^{(-k(i))}(x_i, a)$.
- **Pseudo-Outcome:** $m(x_i; \hat{q}) = \sum_{a=1}^K \pi_e(a \mid x_i) \, \hat{q}(x_i, a)$.
- **Additive Error Decomposition:**
  The estimation error decomposes additively into context sampling variability and reward-model estimation error:
  $$\hat V_{\mathrm{DM}} - V(\pi_e) = \underbrace{\frac{1}{N} \sum_{i=1}^N \big(m(x_i; q^*) - V(\pi_e)\big)}_{\text{Context-Sampling Error } O_P(N^{-1/2})} + \underbrace{\frac{1}{N} \sum_{i=1}^N \sum_{a=1}^K \pi_e(a \mid x_i) \big(\hat{q}^{(-k(i))}(x_i, a) - q^*(x_i, a)\big)}_{\text{Reward-Model Estimation Error } O_P(N_{\mathrm{train}}^{-1/2})}.$$
  *Note on Orthogonality:* While cross-fitting ensures that held-out contexts in fold $k$ are conditionally independent of the training data used to fit $\hat{q}^{(-k)}$, these components are an additive decomposition and are not assumed to have zero unconditional finite-sample covariance without further regularity conditions.
- **Naive Wald Interval Limitation:** The naive empirical variance:
  $$\widehat{\mathrm{se}}_{\mathrm{DM, naive}} = \frac{\widehat{\mathrm{sd}}\big(m(x_i; \hat{q})\big)}{\sqrt{N}}$$
  **treats $\hat{q}$ as fixed and known**. It captures *only* the context-sampling variation (the first term). In finite samples where $\hat{q}$ has non-negligible estimation variance, naive DM intervals systematically undercover. Furthermore, if $\hat{q}$ is misspecified, DM suffers from irreducible asymptotic bias, rendering nominal coverage zero as $N \to \infty$.

### 3.4 Doubly Robust (DR)
- **Estimator:**
  $$\hat V_{\mathrm{DR}} = \frac{1}{N} \sum_{i=1}^N \left( \sum_{a=1}^K \pi_e(a \mid x_i) \, \hat{q}^{(-k(i))}(x_i, a) + w_i \big(r_i - \hat{q}^{(-k(i))}(x_i, a_i)\big) \right).$$
- **Uncentered Influence Score:**
  $$\psi_i^{\mathrm{DR}} = \sum_{a=1}^K \pi_e(a \mid x_i) \, \hat{q}^{(-k(i))}(x_i, a) + w_i \big(r_i - \hat{q}^{(-k(i))}(x_i, a_i)\big).$$
- **Double/Debiased Machine Learning (DML) Properties:**
  1. *Known vs. Estimated Propensities:* In the general semiparametric DML framework (Chernozhukov et al., 2018), both the propensity score $e_0(x, a)$ and outcome regression $q_0(x, a)$ are estimated nonparametrically, requiring the product rate condition $\|\hat{q} - q_0\|_{L_2} \times \|\hat{e} - e_0\|_{L_2} = o_P(N^{-1/2})$ (typically achieved when each rate is $o_P(N^{-1/4})$).
  2. *Current ReversalLab Scope:* In our current synthetic environment, the logging propensities $p_i = \pi_0(a_i \mid x_i)$ are **known exactly and recorded without estimation error** ($\|\hat{e} - e_0\| = 0$). Because the propensities are known, Neyman orthogonality holds exactly, and the estimator enjoys double robustness: it remains $\sqrt{N}$-consistent and asymptotically normal even if $\hat{q}$ is completely misspecified, provided the importance weights have finite second moment $\mathbb{E}[w^2] < \infty$ and support holds.
  3. *Empirical Influence Variance:*
     $$\widehat{\mathrm{Var}}(\psi) = \frac{1}{N-1} \sum_{i=1}^N \big(\psi_i^{\mathrm{DR}} - \hat V_{\mathrm{DR}}\big)^2, \qquad \widehat{\mathrm{se}}_{\mathrm{DR}} = \sqrt{\frac{\widehat{\mathrm{Var}}(\psi)}{N}}.$$
- **Failure Mode under Poor Overlap:** If overlap is weak ($\pi_0(a \mid x) \to 0$ for some actions), the importance weight variance $\mathbb{E}[w^2]$ explodes. The residual term $w_i (r_i - \hat{q}(x_i, a_i))$ exhibits heavy tails, violating the uniform asymptotic normality condition in finite samples.

## 4. Nonparametric Bootstrap Specification

### 4.1 Resampling Unit and Identity-Aware Cross-Fitting
For i.i.d. contextual bandits, the fundamental resampling unit is the full observation tuple:
$$u_i = (x_i, a_i, r_i, p_i) \in \mathbb{R}^D \times \{0, \dots, K-1\} \times \mathbb{R} \times (0, 1].$$
A bootstrap sample $\mathcal{D}^{(b)} = \{u_1^{(b)}, \dots, u_N^{(b)}\}$ is formed by sampling $N$ observations uniformly at random with replacement from $\mathcal{D}$.

**Critical Leakage Protection:**
When an original observation $i \in \{0, \dots, N-1\}$ is drawn multiple times into $\mathcal{D}^{(b)}$ (multiplicity $M_i \ge 1$), naive random row partitioning would allow duplicate copies of observation $i$ to appear simultaneously in a training fold and its evaluation fold.
To prevent out-of-fold data leakage while preserving bootstrap multiplicities:
- Cross-fitting partitions the **unique original observation identities** present in $\mathcal{D}^{(b)}$ into $K$ disjoint groups.
- All bootstrap copies of original observation $i$ are assigned strictly to the same evaluation fold.
- The training folds contain all copies of other observations with their full bootstrap multiplicities.
- Zero copies of observation $i$ ever appear in the training partition used to evaluate observation $i$.

### 4.2 Distinguishing Bootstrap Procedures

1. **Fixed-Model Bootstrap (`fixed_model`):**
   - The predicted reward matrix $\hat{Q} \in \mathbb{R}^{N \times K}$ is kept fixed.
   - When row $i$ is sampled as $u_j^{(b)}$, its corresponding predicted reward row is $\hat{Q}_{i, :}$.
   - **Properties:** Measures context and reward resampling variability, holding the learned model fixed. Fast, but omits model-fitting variability.

2. **Full-Refit Cross-Fitting Bootstrap (`refit`):**
   - In each bootstrap draw $b \in \{1, \dots, B\}$, the complete identity-aware $K$-fold cross-fitting pipeline is rerun on $\mathcal{D}^{(b)}$.
   - Feature preprocessors (scaling) and reward models ($\text{LogisticRegression}$ or $\text{Ridge}$) are refit exclusively on the bootstrap training folds.
   - **Properties:** Fully end-to-end; captures both data sampling variation and reward-model estimation uncertainty. Computationally intensive ($B \times K$ model fits).

### 4.3 Theoretical Properties and Heavy-Tail Limitations

- **Asymptotic Consistency vs. Heavy Tails:**
  Bickel & Freedman (1981) established that the nonparametric bootstrap sample mean is asymptotically inconsistent when the underlying distribution has an **infinite second moment** ($\mathbb{E}[w^2] = \infty$).
  In our synthetic contextual bandit benchmark, propensities are bounded away from zero on compact regions, so theoretical moments are technically finite. However, under poor overlap, the variance $\mathbb{E}[w^2]$ is extremely large. In finite samples, this produces severe kurtosis and heavy-tail behavior:
  - Rare observations with extreme weights dominate individual bootstrap resamples.
  - Bootstrap quantiles exhibit high Monte Carlo instability across resamples.
  - Consequently, bootstrapping does **not** repair poor-overlap undercoverage in finite samples, even though it is not strictly inconsistent in an asymptotic sense with bounded support.

## 5. Scope of Validity and Limitations

1. **Monte Carlo Uncertainty in Calibration:**
   Evaluating empirical coverage across $M$ independent Monte Carlo replications incurs a binomial standard error $\sqrt{\text{coverage}(1 - \text{coverage})/M}$. For $M = 100$, this error is $\approx 2.2\%$; for $M = 500$, it is $\approx 0.97\%$. Reported calibration percentages must be interpreted within these standard error bands rather than treated as exact mathematical equalities.
2. **Heuristic Nature of Diagnostics:**
   Diagnostics such as Kish's effective sample size (ESS), maximum weight share, and mean weight z-scores are *operational heuristics*. They flag adverse sampling conditions (such as weight concentration) but do not constitute formal hypothesis tests that mathematically prove whether an interval has undercovered on a specific dataset.
3. **Unmodeled Real-World Complexities:**
   The guarantees herein apply to stationary, independent contextual bandits with known logging propensities. They do not generalize to unobserved confounding, adaptive logging policies, dynamic exploration, or clustered longitudinal dependencies.

### 4.3 Confidence Interval Constructions

Given $B$ bootstrap estimates $\{\hat V^{(b)}\}_{b=1}^B$ and point estimate $\hat V$:

1. **Percentile Interval:**
   $$[L_{\mathrm{perc}}, U_{\mathrm{perc}}] = \big[\hat q^B_{\alpha/2}, \, \hat q^B_{1-\alpha/2}\big].$$
   Transformation-invariant; robust to moderate skewness, but requires exchangeability and large $B$.

2. **Basic (Pivotal / Empirical Quantile) Interval:**
   $$[L_{\mathrm{basic}}, U_{\mathrm{basic}}] = \big[2\hat V - \hat q^B_{1-\alpha/2}, \, 2\hat V - \hat q^B_{\alpha/2}\big].$$
   Derived from the pivotal quantity $R = \hat V^* - \hat V$. Reflects asymmetric sampling distributions in the correct direction.

3. **Normal Bootstrap Interval:**
   $$[L_{\mathrm{norm}}, U_{\mathrm{norm}}] = \hat V \pm z_{1-\alpha/2} \, \widehat{\mathrm{sd}}_B\big(\{\hat V^{(b)}\}\big).$$
   Replaces asymptotic formula standard errors with the bootstrap Monte Carlo standard deviation.

## 5. Summary of Calibrated Inference Criteria

| Estimator | Primary CI Method | Theoretical Basis | Major Failure Mode |
|---|---|---|---|
| **IPS** | Wald / Studentized | Classical CLT | Heavy-tailed weights (poor overlap) $\implies$ extreme undercoverage. |
| **SNIPS** | Delta-Method Wald / Basic Bootstrap | Delta Method on Bivariate CLT | Ratio bias at small $N$, skewness under poor overlap. |
| **DM** | Full-Refit Bootstrap | End-to-end nonparametric resampling | Model misspecification causes persistent bias (coverage $\to 0$). |
| **DR** | Influence-Score Wald / Full-Refit Bootstrap | DML Neyman Orthogonality & CLT | Heavy-tailed weights inflate residual variance $\implies$ undercoverage. |
